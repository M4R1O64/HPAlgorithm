# HPAlgorithm
### 백준(BOJ) 1845번 문제 - '## ##'
Anne Bergeron의 'A Very Elementary Presentation of the Hannenhalli-Pevzner Theory' 논문을 토대로 제작했습니다.

논문에서는 'Reduced Form' 이라는 것을 이용하지만, 정확한 설명이 없어 생으로 Hurdle을 구했습니다.

왜 통과된건지는 저도 모르겠습니다...

추가로 올린 999바이트 코드는 이후에 단순히 Oriented Pairs가 최대인 것만 찾아 회전시키도록 만들어 길이를 대량으로 줄여낸 코드입니다.

그래서 해당 문제에서 본 코드가 유일한 1000바이트 미만 코드입니다.
